# Eccles Agent v1.0: first public release

Tell your phone what to do. Watch it happen. Stop it with one tap.

## Install (no computer needed)
1. Install the APK (allow "Install unknown apps" if asked).
2. Open the app, then `Settings → Accessibility → Eccles Agent` and try to turn it on. Tap OK on the "Restricted setting" message (Android 13+).
3. `Settings → Apps → Eccles Agent → ⋮ → Allow restricted settings`, confirm, then turn the Accessibility service on.

Prefer a computer? `adb install -r EcclesAgent-1.0.apk` also works. Full steps in the README.

## You need an AI API key
Gemini: https://aistudio.google.com/apikey
OpenAI: https://platform.openai.com/api-keys
Claude: https://platform.claude.com/settings/keys

## Highlights
- Plain-language control by text or mic
- Gemini, OpenAI, Claude or any OpenAI-compatible endpoint
- Accessibility-first execution with verified fallbacks
- Excluded apps (banking and payments), password-screen stop, confirmation gate, always-visible Stop

Requires Android 8.0+. Not distributed on Google Play.
